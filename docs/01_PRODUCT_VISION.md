# Product vision

## Vision statement

Create the administrative backbone for a small or medium-sized association using WordPress.

The product should combine:
- structured member and organization data
- board history
- practical meeting support
- decisions and action tracking
- minutes and document handling
- controlled publication to the public website

The plugin should feel like a natural WordPress capability, not a separate enterprise application embedded in wp-admin.

## Product identity

The plugin is not merely a member register.

Its differentiator is that it supports the association's actual working loop:

**prepare → meet → record → decide → finalize → sign/archive → publish/follow up**

## Key value propositions

### One source of truth

Structured data is entered once and reused.

### Institutional memory

Historical board assignments, memberships, meetings, decisions and documents remain queryable.

### Meeting administration that reduces secretary workload

Meeting notes are captured under agenda items while the meeting happens, then reused to create minutes.

### Practical paper support

A finalized document can be printed, signed by hand and uploaded as the signed archival copy.

### WordPress-native publication

Dynamic Gutenberg blocks can expose approved public information without manual copying.

## Product test

For each feature ask:

> Does this help the association maintain its people, governance, meetings, decisions, documents or publication?

If no, integration with another plugin/service is usually preferable.
